01 / Phase Overview

Why This Phase Matters

Selecting the safeguards that will protect Foxhole Portal.

The Select phase turns the approved Moderate categorization into a defined set of security requirements for Foxhole Portal.

The authorization team reviews the Moderate baseline, identifies controls that are inherited from enterprise services, and documents any tailoring needed for the system environment.

These decisions establish what must be implemented, who is responsible, and what evidence will be needed during assessment.

Control Selection Decision

Foxhole Portal will use the NIST SP 800-53 Rev. 5 Moderate baseline with approved tailoring, control allocation, and inherited control decisions documented before implementation begins.

Phase Objectives

What the team needed to define.

The Select phase focused on choosing the appropriate security control baseline, tailoring the controls, identifying inherited protections, and assigning implementation responsibility.

01

Select the Baseline

Use the approved Moderate categorization to identify the starting NIST SP 800-53 Rev. 5 control baseline.

02

Tailor the Controls

Review control applicability and document retained, supplemented, inherited, and not-applicable controls.

03

Assign Control Ownership

Identify the teams responsible for implementing, maintaining, and supporting each selected control.

04

Approve the Control Set

Document the final control selection and obtain approval before implementation begins.

Control Selection Summary

The approved protection strategy.

The selected control set combines system-specific, common, and hybrid controls. Each control is assigned to the team responsible for implementation and supporting evidence.
