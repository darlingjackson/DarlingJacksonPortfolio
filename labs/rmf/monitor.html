01
MONITOR // PHASE OVERVIEW

Authorization is maintained through continuous awareness.

Monitor is not a one-time closeout activity. The system and its environment continue to change, so risk information, control effectiveness, corrective actions, and authorization records must remain current.

01 // OBSERVE Track Change

Watch the system and environment for changes that may affect security, privacy, architecture, or risk.

CHANGE AWARENESS
02 // ASSESS Reassess Controls

Perform ongoing assessments at the frequencies defined by the continuous monitoring strategy.

CONTROL EFFECTIVENESS
03 // RESPOND Address Risk

Analyze monitoring results, vulnerabilities, findings, and POA&M status and respond to risk as needed.

RISK RESPONSE
04 // UPDATE Refresh the Record

Update plans, assessment information, POA&M data, and other authorization records when conditions change.

PACKAGE UPDATES
05 // REPORT Support Ongoing Authorization

Report system posture and give decision-makers current information to determine whether risk remains acceptable.
