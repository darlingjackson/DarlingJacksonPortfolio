# ⭐ Featured Project

## Enterprise Security Compliance Lab

One of the projects I'm most proud of is my **Enterprise Security Compliance Lab**.

Instead of simply reading about the Risk Management Framework (RMF), I wanted to build something that showed what the process actually looks like from beginning to end.

To do that, I created a fictional defense contractor called **Blue Fox Defense** and an enterprise system called **Foxhole Portal**.

Throughout the lab you'll follow the system as it moves through each phase of the RMF while reviewing the meetings, decisions, documentation, and security activities that help move the system toward authorization.

My hope is that someone visiting this project doesn't just read about RMF—they experience it.
